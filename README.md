# SFIDM - Version 3 (Pro Controls, Auto-Category Folders, Scheduler, Speed Limiter & PIN Vault)

## New Features in Version 3
- **Auto-Category Folders:** Downloaded files automatically organize into `Downloads/SFIDM/Videos`, `Audio`, `Images`, `Documents`, `Archives`, `Apps`, and `Others` with 1-tap folder filter chips.
- **Download Scheduler:** Schedule any download to start automatically at a specific time (+15m, +1h, 2:00 AM, or custom steps).
- **Speed Limiter & Wi-Fi Only Mode:** Limit download bandwidth (Unlimited, 512 KB/s, 1 MB/s, 2 MB/s, 5 MB/s) across both HTTP multi-thread & yt-dlp engines, plus auto-pause on mobile data when Wi-Fi Only is active.
- **PIN-Locked Private Vault:** 4-digit PIN protected vault that stores files inside hidden internal storage (`.nomedia`), completely invisible to the Gallery and file managers, with auto-lock on background and 1-tap move/export.
